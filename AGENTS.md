# Commit standards

All commit messages must follow the Conventional Commits specification.

Format:

<type>(<scope>): <short summary>

Examples:
- feat(api): add movie discovery endpoint
- fix(ci): ensure PR workflow checks run on pull requests
- chore(repo): add conventional commit policy

Allowed types include: feat, fix, docs, style, refactor, perf, test, build, ci, chore, revert.
Use a lowercase type and a concise summary in the imperative mood.
